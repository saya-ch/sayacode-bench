# 云服务跑评测：时间与金钱成本估算（2026-11-03）

> 基于 v2 实测（240 trial：sayacode 90.1M + mini-swe 118.7M + Codex 103.0M = **312M tokens**；单 trial 均值 12.8 分钟、并发 2 约 36 小时）。
> 价格来源：[阿里云 r7 16C/64G 约 ¥3.5–5/h](https://blog.zestp.com/archives/36460)、[DeepSeek 官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)（[V3 输入 ¥0.5(命中)/¥2(未命中)/百万、输出 ¥8/百万](https://jnzstatic.cs.com.cn/zzb/htmlInfo/adb8d61751b3254a96596535385ab926.html)）、[AWS c6i 系列](https://umbrellacost.com/learning-center/aws-cost-optimization/ec2/c6i)。价格为量级参考，实际以开通时为准。

## 一、机器选型

- 评测是 **CPU + 内存 + 磁盘** 型任务，**不需要 GPU**。
- 推荐：**16 vCPU / 64GB RAM / 500GB–1TB SSD** 的通用型实例（阿里云 r7.4xlarge 或 AWS c6i.4xlarge）。
- 64GB 内存允许 Docker VM 给 40GB，**并发可到 6–8**（本地 15.6GB 只能 2）。

## 二、时间估算（v2 单 trial 12.8 分钟，含补跑/崩溃系数 1.5）

| 实验 | trial 数 | 并发 6 | 并发 8 |
|---|---|---|---|
| 20×2×2 A/B（40 题） | 80 | ~4–5 h | ~3–4 h |
| 多模型矩阵（40 题） | 480 | ~26 h（1.1 天） | ~19 h（0.8 天） |
| **扩样 100 题** | **600** | **~32 h（1.3 天）** | ~24 h（1 天） |

## 三、金钱估算

### 场景 A：云 VM + 现有 Magpie（内部额度，无 token 费）

| 项 | 估算 |
|---|---|
| 实例 16C/64G × 32h | ¥4/h × 32 = **¥128** |
| ESSD 500GB × 32h | ~¥15 |
| 拉 100 题镜像流量（~100GB） | ~¥0–50（入流量多免费） |
| **合计** | **约 ¥150–250** |

- 前提：云实例能访问 Magpie（VPN / 公网暴露 / 把 Magpie 部署到云），网络配置另花时间。
- **模型的 token 成本为 0**（内部额度）。

### 场景 B：云 VM + DeepSeek API（云上直连大模型）

| 项 | 估算 |
|---|---|
| 实例 + 存储 + 流量（32h） | ~¥165 |
| **模型 token（600 trial ≈ 780M tokens）** | **¥1300–2000** |
| **合计** | **约 ¥1500–2200** |

token 明细（780M：input 85%、其中 cache 命中 70%）：
- input 命中 464M × ¥0.5 = ¥232
- input 未命中 199M × ¥2 = ¥398
- output 117M × ¥8 = ¥936
- 合计 ≈ **¥1566**（用 reasoner 输出 ¥16 则 ≈ ¥1900+）

## 四、关键结论

1. **模型 token 是最大成本**：600 trial 的 DeepSeek API 约 ¥1300–2000，是机器（¥150）的 **8–13 倍**。
2. **用内部 Magpie 可把总成本压到 ¥150–250**，代价是要打通云到 Magpie 的网络（VPN/公网/或把 Magpie 上云）。
3. **云的价值是时间**：本地 4 天（并发 2）→ 云 1–1.5 天（并发 6–8），机器只花 ¥150。
4. **并发受模型 API 速率限制**：DeepSeek 有 TPM/RPM 限制，实际并发可能达不到 6–8，时间会拉长。
5. **对比本地**：本地几乎只花电费（~¥5），但 4 天；云多花 ¥150（不含 token）换 2–3 天时间。

## 五、建议

- **首选**：云 16C/64G + **内部 Magpie**（打通网络），总成本 ¥150–250，1–1.5 天跑完 100 题。
- 若不能打通 Magpie：云 + DeepSeek API，总 ¥1500–2200；可先用 20 题小样本（~¥100）验证链路与成本。
- 先跑 **20×2×2 A/B（~¥20–300）** 验证云端链路，再决定是否扩样。
- 注意：云实例按小时计费，跑完立刻释放；镜像拉取与结果回传（15GB）另计少量流量。
