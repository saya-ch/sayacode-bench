## 观察

本机 Docker 环境中，多个固定镜像的官方参考解出现不一致结果；OpenLibrary 有 pytest `SIGSEGV`，qutebrowser 有 AST／pytest 内部类型错误。不同次运行的实际镜像、架构与资源已经核对，异常并非全是正常功能断言失败。

因此没有将“运行过一次 gold 就通过”作为足够的正式准入，也没有通过只保留碰巧通过的任务来发布成绩。
